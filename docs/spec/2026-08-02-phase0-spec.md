# Spec: Điểm Danh HN2 SOC — Phase 0 (MVP: Luồng 2 — Đối chiếu từ csv)

## Objective

Xây **lõi MVP** của app điểm danh kiểm-soát có/vắng/trễ cho nhân viên kho chuyển phát nhanh (SPX), **chỉ luồng 2**: đối chiếu từ danh sách chấm công đã có sẵn (csv → GSheet).

User story chính (Phase 0):
1. Quản lý mở task "Đối chiếu" cho 1 tổ hợp (station, slotCode, team).
2. App đọc danh sách NV khớp từ `StaffData` (dữ liệu đồng bộ từ csv hệ thống), **batch ghi 1 lần** vào Log với `timeRef = taskCreated`, trạng thái khởi tạo `Vắng`.
3. Quản lý quét barcode từng NV → app ghi `timeScan`, trạng thái `Có mặt`. Quét NV không có trong task → thêm dòng `Dư`.
4. Kết thúc task → khóa quét, hiển thị bộ đếm `Đã quét / Vắng / Dư`.

Mục tiêu success: quản lý thấy ngay danh sách có/vắng/trễ đúng như csv phản ánh, không ghi đè dữ liệu chấm công, không deadlock Station A/B, performance ổn cho 500–1000 NV.

## ASSUMPTIONS I'M MAKING (sửa tôi nếu sai)

1. Stack giữ nguyên GAS: **clasp + Apps Script + Spreadsheet**, WebApp `doGet()` trả HTML. Không dùng framework frontend.
2. **Không copy source v1** — chỉ mượn pattern: cache wrapper, batch `setValues()`, LockService.
3. Sheet `StaffData`: dữ liệu đồng bộ từ csv, **giữ header tiếng Anh như `Att.csv`** (No., Date, Staff ID, ..., Slot Code, ..., Station, ...). Phase 0 chưa làm tự-động hóa đồng bộ — mặc định **dán/thay dữ liệu thủ công** (đồng bộ tự động = Phase 2+).
4. 1 GAS project duy nhất, nhiều sheet: `Config`, `StaffData`, `AttendanceTask`, `AttendanceLog`.
5. Cột code/sheet tiếng Anh, hiển thị web tiếng Việt.
6. Barcode quét = nhập `staffId` (Ops…) vào input + Enter.
7. Thời gian dùng timezone của Spreadsheet (không gọi `Session.getScriptTimeZone()` trong vòng lặp).
8. Phân quyền Phase 0: ai truy cập WebApp cũng tạo/quét/đóng task được (bỏ qua auth — ghi chú rủi ro).

## Scan Classification Logic (đưa vào tests)

Input: `row` (NV trong task log) + `staffIndex` (StaffData) + `task` (station/slotCode/team).

1. NV có trong task log + `timeScan` rỗng → update `timeScan = now`, status = `Có mặt`.
2. NV có trong task log + `timeScan` đã có → **bỏ qua (đã điểm danh)** — trả về thông báo "Đã điểm danh", không ghi đè.
3. NV không có trong task log:
   - Có trong `StaffData` với (station, slotCode, team) **khớp task** → thêm dòng status `Dư` (không nằm trong danh sách chốt lúc tạo task — Q6 đã chốt: danh sách chốt là tham chiếu cố định).
   - **Khác** (có trong `StaffData` nhưng khác tổ hợp, HOẶC không có trong `StaffData`) → thêm dòng status `Dư`.
   → Không còn nhánh `Trễ` — gộp tất cả "không nằm trong danh sách chốt" vào `Dư`.
4. Task `status != open` → từ chối quét.

Counters: `Đã quét` = count(status=Có mặt + Dư) — số NV có `timeScan`; `Vắng` = số trong pre-fill chưa có `timeScan`; `Dư` = count(status=Dư).

## UI (index.html — tiếng Việt)

- **Màn hình danh sách task**: bảng `Mã task | Station | Ca | Team | Trạng thái | Tạo lúc`; nút `+ Đối chiếu`.
- **Modal tạo task**: dropdown `Station` (mặc định từ Config) → `Ca (Slot Code)` → `Team` (load theo station); nút `Tạo`.
- **Màn hình quét**: input `Quét mã nhân viên…` (auto-focus, font sans-serif rõ); bộ đếm `Đã quét / Vắng / Dư`; bảng NV: `Mã NV | Tên NV | Ca | Team | Card In | Card Out | Giờ có mặt | Giờ quét | Trạng thái`; nút `Kết thúc` (nền đỏ).
- **Không có** state `Chờ bàn giao`, không có Station A/B blocking.
- Empty-state chính xác: "Chưa có nhân viên nào quét" **chỉ** khi chưa có `timeScan`; nếu pre-fill đã có dòng thì hiển thị bảng với badge `Vắng`.

## Code Style

```js
// Database.gs — ví dụ style
function readStaffIndex_() {
  const cacheKey = 'staffIndex_v1';
  const cached = staffCache.get(cacheKey);
  if (cached) return JSON.parse(cached);
  const values = getSheet_(SHEETS.STAFF_DATA).getDataRange().getValues();
  const index = buildStaffIndex_(values); // { [staffId]: {staffName, slotCode, station, team, workstation, cardIn, cardOut} }
  staffCache.put(cacheKey, JSON.stringify(index), CACHE_TTL.STAFF_INDEX);
  return index;
}
```

- Private: `_camelCase` (hậu tố `_` cho private trong module .gs).
- Hằng số: `Config.gs` — `SHEETS`, `COLS`, `STATUS`, `CACHE_TTL`, `UI_LABELS`.
- Không gọi API GAS trong vòng lặp; batch `setValues()`; cache version-key (`_v1`) để invalidate dễ.
- UI: template literals, id tiếng Anh, label tiếng Việt, font system sans-serif.

## Testing Strategy

- **Node thuần** (`node:test`, không cần mô phỏng GAS) cho:
  - `csv-normalize`: trim tên (xử lý double-space `Đào  Quang  Hà`), chuẩn hóa staffId.
  - `scan-classify`: toàn bộ bảng phân loại (Có mặt/Vắng/Dư/đã điểm danh/đóng task).
  - `task-filter`: filter StaffData theo (station, slotCode, team) — đếm khớp với dữ liệu mẫu `Att.csv` (VD: HN2 SOC + 08:00-17:00 + Outbound).
- **Manual GAS test** (sau khi `clasp push`): tạo task thật trên sheet test, quét vài mã, kiểm tra pre-fill + update + counters.
- Không viết test cho HTML UI ở Phase 0 (manual QA).

## Boundaries

- **Always:** chạy `npm test` trước mỗi commit; validate input (`staffId` non-empty, taskId tồn tại); lock trước ghi (`LockService.getScriptLock()`); giữ `timeRef`/`timeScan` là `Date` (không ghi string rời rạc); trim tên NV.
- **Ask first:** thay đổi schema sheet, thêm dependency, thay đổi cấu trúc thư mục, quyết định public/private repo, quyết định commit `Att.csv` (dữ liệu chấm công thật).
- **Never:** commit `.clasprc.json`, `node_modules/`, scriptId thật nếu nhạy cảm; gọi `Session.getScriptTimeZone()` trong vòng lặp; `SpreadsheetApp.appendRow()` trong vòng lặp quét; sửa/ghi đè dữ liệu `StaffData` từ app (app chỉ đọc); viết đè cột `cardIn`/`cardOut`.

## Success Criteria

1. `npm test` xanh (các case phân loại + normalize + filter).
2. Tạo task (station, slotCode, team) → Log được pre-fill **1 lần** đúng số NV khớp csv; `timeRef = createdAt` cho mọi dòng.
3. Quét NV đúng task → `timeScan` + `Có mặt`; quét lại → từ chối "Đã điểm danh"; quét NV không trong pre-fill → `Dư`; quét khi task `done` → từ chối.
4. Bộ đếm đúng quy ước (xác nhận ở review).
5. WebApp hiển thị tiếng Việt, không dot-matrix, không `?` ở cột Team, không deadlock, không quá 6 phút khi pre-fill 1000 NV (batch setValues).
6. Không commit file credentials; repo GitHub `van90bg/diem-danh-hn2-soc` có code + docs.
